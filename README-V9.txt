SHAKSHUKA TRAVEL V9 - EVENT-LEVEL SKYDIVE LOGBOOK

Replace:
- admin.html
- admin.js
- event.html
- event.js
- styles.css

Add:
- database/event-logbook-v9.sql

Run event-logbook-v9.sql once in Supabase SQL Editor.

Features:
- Skydive-only event-level logbook
- Add days
- Add non-sequential but increasing load numbers
- Add multiple groups per load
- Assign event participants to each group
- Assign Ilya / Ksenia / No coach to a group
- Optional jump type / notes
- Participant logbook is generated automatically
- Coached jumps show the coach name

Future improvements can include drag/drop, copy previous load, statistics and exports.
